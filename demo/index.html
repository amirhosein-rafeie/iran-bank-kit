تشخیص و اعتبارسنجی بانک‌های ایرانی

کتابخانهٔ iran-bank-kit برای تشخیص بانک از شماره کارت و شبا، بررسی رقم کنترلی و نمایش لوگو در جاوااسکریپت و ری‌اکت.

فهرست به‌روزشدهٔ ۳۳ بانک و مؤسسهٔ ایرانی؛ شامل بانک مرکزی، ایران–ونزوئلا و ایران‌اروپا، همراه با نگاشت شناسه‌های بانک‌های ادغام‌شده به بانک جانشین. جزئیات پوشش و منابع ↗

آخرین به‌روزرسانی: ۲۰۲۶/۱۰/۲۲JavaScript / TypeScriptهسته بدون وابستگیمجوز کد: MIT

مستندات کامل ↗

نصب بسته

npm install iran-bank-kit

هسته را از iran-bank-kit و کامپوننت‌های ری‌اکت را از iran-bank-kit/react وارد کنید.

JavaScript / TypeScript
import {
  detectBankByCardNumber,
  formatCardNumber,
  maskCardNumber,
  validateIranianCardNumber,
} from 'iran-bank-kit';

detectBankByCardNumber('610433')?.key; // 'mellat'
formatCardNumber('6104330000000011'); // '6104 3300 0000 0011'
maskCardNumber('6104330000000011'); // '6104 **** **** 0011'
validateIranianCardNumber('6104330000000012');
// { valid: false, error: 'invalid_checksum' }
